# Glossary

Plain-language term map: the word users see, the internal term, and a one-line explanation. Every user-facing feature keeps this current.

| Users see | Internal term | Meaning |
|---|---|---|
| RSS Feed Sources | `sourcesJson` | the feed addresses (URLs) the widget reads |
| Hide Articles Matching | blacklist, `excludeRegexJson` | words or regular expressions that hide matching articles for good |
| Search articles | search field, filter query | plain text that narrows the list until it is cleared |
| Refresh Interval | refresh timer | minutes between reloads of all feeds |
| Widget Title | custom title | optional heading above the list |
| Widget | plasmoid, applet | the thing the user adds to the desktop or panel |
